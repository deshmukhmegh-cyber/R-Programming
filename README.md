# Cybersecurity Data Analysis - Assignment 2

This repository contains the work for **Assignment 2** of the Cybersecurity Data Analysis course. The assignment focuses on analyzing data related to cyberattacks, cybersecurity threats, and data breaches across industries. The goal is to understand how industries are affected by cyberattacks, evaluate the effectiveness of security controls, and examine resulting data losses.

## Branches

- **`assignment1`**: Contains the code and solutions for **Assignment 1**.
- **`feature-branch-assignment2`**: Contains the code and solutions for **Assignment 2**.

## Datasets

Three key datasets are used in the analysis:

1. **[Cyberattack Data]**:(https://github.com](https://www.kaggle.com/datasets/shakirul09/cyber-crimes-dataset)
 Information about different types of cyberattacks and their impact on industries, including attack severity, attack types, and data compromised.
2. **[Global Cybersecurity Threats Data]**:(https://www.kaggle.com/datasets/atharvasoundankar/global-cybersecurity-threats-2015-2024) Data on global cybersecurity threats, including defense mechanisms and the number of affected users.
3. **[Data Breach Data]**: (https://catalog.data.gov/dataset/5-12-cybersecurity-detail-d8bb7) Information about recent data breaches, including the attack type, industry type, and number of affected users.

## Objectives

- **Data Cleaning**: Filtering the datasets to focus on relevant columns and ensuring data consistency.
- **Data Merging**: Merging datasets to get a complete view of the cybersecurity landscape across industries.
- **Modeling**: Fitting models like Generalized Linear Models (GLM) and Generalized Additive Models (GAM) to explore relationships between attack severity, attack types, and data loss.
- **Visualization**: Generating visualizations like bar charts, pie charts, and bubble charts to better understand the data.

## Key Features

- **GLM and GAM Models**: Used for analyzing attack severity and relationships between cybersecurity factors.
- **Visualizations**: Includes various plots like boxplots, pie charts, and bubble charts to illustrate key insights.
- **Code Organization**: The code is well-structured with meaningful commits to track improvements.
